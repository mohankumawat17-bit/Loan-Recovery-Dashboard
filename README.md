# Loan Recovery Dashboard

A professional Loan Recovery Dashboard built using Streamlit, Pandas and Plotly.

## Features

- Interactive KPI Cards
- Recovery Analytics
- Outstanding Analysis
- DPD Analysis
- Location & SHO Filters
- Business Insights
- CSV Export
- Interactive Charts

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Technologies Used

- Streamlit
- Pandas
- Plotly
- Openpyxl
